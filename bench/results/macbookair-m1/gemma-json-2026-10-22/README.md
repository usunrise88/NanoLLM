# gemma.json на MacBook Air M1 8 ГиБ, Metal (2026-10-22)

Пять запросов `gemma.json` (сводки встречи по транскрипту, температура 0) один за другим к одному `nanollm serve` на `llamacpp:mtl0`,
скрипт `bench/results/rusunrisebook/baseline-2026-10-20-gemma-igpu-uma4g/run_steps.py`; сервер с предзагруженной моделью, MTP,
питание от сети. Здесь только числа (`summary.json`); ответы модели лежат вне репозитория, потому что в промптах транскрипт.
Конфигурации: `a-uma4g-mtp2` (как в базовом замере на Iris Xe: пресет uma-4g, `n_max` 2) и `b-uma5g-mtp3` (бюджет выведен из
устройства, это uma-5g, `n_max` 3). Во время прогонов доступно было 16–19 % памяти (открыты приложения), прогоны по одному.
